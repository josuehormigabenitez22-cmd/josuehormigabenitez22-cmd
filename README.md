# Josué Hormiga Benítez

Data Scientist and mathematician (University of Cádiz, MSc in Big Data & Data Science). I work on deep learning for remote sensing and on time-series forecasting.

- **Telespazio Ibérica (2026):** fine-tuned Faster R-CNN and Mask R-CNN models to detect people, ships, vehicles and drones in aerial imagery, trained a Mask R-CNN to segment burned vegetation, fire and smoke (F1 0.74–0.88), and built a neural-network downscaling model for WRF-SFIRE (1 km → 100 m).
- **Puerto del Rosario City Council:** time-series models to forecast municipal spending, cutting forecast error from 40% to 15%.
